# Agent Note：模型菜单带上价格，而它并不需要知道什么是价格

Status: implemented

[English](2026-08-31-model-row-price-hints.md) | 中文

## Problem

`sci` 部署如今卖的是各机构自己挑过的目录，费率也由机构自己定：gate 持有一份带公开价的模型池和一个按机构设定的转售倍率，`dsh-sci-models` 已经让这份目录决定一个会话可以调用哪些模型。唯独「一个模型多少钱」看不见。研究者在 composer 的模型菜单里在 flash 档与 pro 档之间做选择时，看到的只是两个名字，而两者之间是他即将花掉的每一个 token 上三倍的差价。

该显示它的地方显然是菜单行，而菜单属于 `ui-model-selection`——一个不知道 gate、机构与金额为何物的包，也不该开始知道。座位的注入面同样不是一块随便用的画布：客户端栈的 props 纪律只接受可序列化的数据与回调，渲染内容一律走槽位，所以「让 sci 包传一个 ReactNode 进去」从来就不是可选项。

## Decision

`ui-model-selection` 只长出一条通用接缝，不长任何词汇。`ctx.modelDirectories.registerHints(source)` 同一时刻只接受一个来源——已有来源时再注册会抛错，而不是把占位权交给注册顺序——并返回它的 disposer。来源给出的是 `ModelHint` 行：一个提供方 id、一个模型 id，以及 `lines`——已经本地化好的纯字符串。座位在挂载时读取当时登记的那个来源，只问一次，并把每组 lines 放到提供方与模型都完全匹配的那一行上。该包不解析这些文字，而没有来源的组合渲染出的仍是它此前渲染的那个菜单。

这些行走的是共用的 `Tooltip` 基元，而不是菜单卡片内部的纯 CSS 浮层。卡片会裁切：`.menu` 为了圆角面与吸顶分组标题是 `overflow: hidden`，`.groups` 还要滚动，因此放在行内的气泡在需要溢出的第一行就被切掉。`Tooltip` 是按锚点 rect 定位的 `position: fixed`，正是侧边栏图标栏标签已经在用的那条逃逸路径。每一行都挂一个锚点，无论有没有 hint，用 `disabled` 开关气泡：Tooltip 的禁用锚点是同一个元素、同一份 DOM，因此菜单已经打开时才落地的 hint 会到达那一行本身，而不是把它重新挂载一遍。又因为悬浮气泡对从不悬浮的人不可读，同一组文字还渲染在按钮外的一个视觉隐藏元素里，由该行用 `aria-describedby` 指向——放在按钮外，是因为放在按钮内这些文字会并入该行的可访问名称，而这一行的名称是它的模型。

`ui-sci-conversation` 贡献本产品唯一的那个来源。它读 `GET /gate/api/models`——对 sci-gate 提供该页面的同源发起、带 cookie，因此浏览器侧代码里不出现任何凭据——并把每条有价的行变成按每百万 token 的美元、保留四位小数的输入价、输出价与缓存命中价；只有当机构的转售倍率不是 1.000 时，才追加那个倍率与它实际收取的价格。倍率作用在整数 micro-USD 上，然后才做显示舍入，因此报出的实际价与计费所用的是同一套算术。行里的 gate `route` 直接当作客户端提供方 id 使用，因为 `dsh-sci-models` 正是用 `camel-api` 与 `deepseek-official` 这两个字符串注册的；本次构建没有对应提供方的 route 只是匹配不到任何行。这条注册待在自己的 `ctx.inject(['modelDirectories'])` 分叉里，而不进插件的依赖声明，因此没有模型菜单的组合只是少了价格行，别的照旧。

同一份 gate 答案里发布的峰谷时段表有意不被引用。它是随时钟变化的折扣，而一个随小时变化的数字出现在读者正在比较模型的地方，会被读成模型的价格。

## Alternatives considered

**注入面上放一个返回 `ReactNode` 的 `modelHint`。** 依客户端栈自己的规则否决：注入面承载 JSON 兼容的数据与回调，渲染内容走槽位。改成纯文本行还让这条接缝可以按数据来测，并把每一个渲染决定——气泡、描述、顺序——留在拥有菜单的那个包里。

**在选项行内部做 CSS `:hover` 浮层。** 因菜单卡片会裁切而否决。手写那条逃逸路径等于在这一个菜单里把 `Tooltip` 的固定定位、视口贴边与 hover/focus 配对重新推导一遍。

**让 `ui-model-selection` 自己去读 gate。** 否决：它是本仓库自带的模型选择器，会出现在没有 gate、没有机构、也没有金额的组合里。价格是 sci 部署的事实，而已经为身份与余额读 gate 的那一层就是 sci 层。

**由 Host 经既有的 `ModelDirectory` 通道把价格推下来。** 是推迟，不是否决。`dsh-sci-models` 手上就有它用来放行目录的同一份费率表，把价格经 `session.models` 送下来会让浏览器只有一个权威而不是两次读取。这需要改 `api/remotes` 的 wire 契约并加一层 Host 侧投影；而浏览器直读今天就能拿到同样的行、且不动协议，引入 `dsh-sci-models` 的那篇 note 也已经记下了这一分工。

**让 `ui-sci-conversation` 把模型服务写进硬 `inject`。** 否决：那会让对话皮肤在任何没有模型菜单的组合里拒绝加载，而这个主张远大于「有菜单的地方就把价格显示出来」。

## Consequences

composer 的模型行现在会说出它的价钱，用的是本部署在别处一贯的币种与位数；只有确实存在加价时才说出机构的倍率。承载它的接缝与贡献方无关：另一个部署可以用配额、区域或下线日期去标注同样的行，而不必碰这个菜单。

设计带来两条边界，两份 README 都已记下。来源每次挂载只读一次、没有任何轮询，因此机构改的费率要等菜单下一次挂载才会到达已经打开的页面，而不是立即到达。以及这些行是标价：当前这一分钟真正的计费口径（含峰谷）留在 credit 流水里——那是唯一知道实际扣了多少的界面。

## Testing

`ui-model-selection` 的组件测试钉住被标注的行：该行指向的描述元素、悬浮时气泡里的两行、相邻未标注行不带 `aria-describedby`、目录里没有的模型其 hint 不标注任何行、来源 reject 时每一行都保持原样、以及座位卸载之后才到达的答案什么也不改。它的插件测试在真实服务上钉住这条接缝：没有来源时注入面上不带 `loadHints`、注册之后正是那个来源、第二次注册抛错、以及 disposer 只会释放属于它自己的那次注册。`ui-sci-conversation` 新增的测试用注入的 fetch 钉住这次 gate 读取——URL 与同源凭据、四位小数金额与三位小数倍率的逐字结果、一行与两行的分叉（含折扣）、每一种畸形或无价的行被丢弃而相邻的好行留下、以及拒绝、不可达、答非所问的 gate 到达菜单时都是一个空列表——它的插件测试则钉住这次贡献本身，包括在没有模型菜单的组合里其余每一项贡献照常落地。`packages/client/ui-sci-conversation/src` 的逐文件覆盖率为 100%；model-selection 的 client 文件仍在客户端通道既有的覆盖率豁免内，本次新增的每一行都被执行到。

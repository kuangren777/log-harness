# Agent Note: Scheduling gates for the science profile — adversary in every plan, task-resolved tier, delegation scope

Status: implemented

English | [中文](2026-08-30-sci-scheduling-gates.zh.md)

## Problem

`clawsgo-analysis/CLAWSGO-SCHEDULING.md` reads 28 transcripts of the studied platform from the scheduling angle and lists nine defects. Checked against `packages/sci/`, three were already closed by construction (relayed consent — a delegated child's `approval/policy` is pinned to `never`; pointer-prompt drift — `sci-prompt`'s reminder→chapter invariant; declaration as authorization — `sci-tier`'s latch) and the rest were open. The tier was still bound before the task was known: a session composed at `balanced` facing a task that needs a real experiment had the suggestion tool as its only exit, and the balanced text offered that exit for research tasks alone, which is the exact shape in which the platform's model built a hollow reproduction and delivered invented numbers (§3). `declare_research_plan` accepted a plan of producers only, so nothing in a swarm was ever asked to break what the swarm produced (§2, §6.2). The Citation and Memory reminders carried "if this turn does not apply, ignore this reminder" clauses, the two rules the platform's transcripts showed drifting to 100% violation and 0% compliance (§4.2). A delegated child's filesystem bound was prose: `sci-workspace` classified a sibling project, the project root, and any dot-directory under the sandbox home as `other` and allowed the read, the path by which the platform's environment-check agent cited four sibling projects (§2.2, §6.3). And no test in `sci-guard` showed the consent property held one layer up.

## Decision

**A plan must contain a refuter.** `validatePlan` gains a composition rule beside its structural ones: at least one agent carries `VERIFIER_ICON` (`security`, the `adversary` persona), and when the plan declares a `PRODUCER_ICONS` agent (`code`, `check` — the personas that leave code, results, or delivered files behind) an edge must lead from one producer into one adversary, so the check runs after the artifact exists and on the artifact itself. A read-only swarm (`web`, `search`) satisfies the rule with a parallel adversary. The archived two-agent install call is now refused and is kept in the tests as the refused shape, with `AUDITED_INSTALL` as the accepted one. The tool description and the cluster text state the rule, so the model does not learn it from a refusal.

**The tier can be resolved by the task.** `sci-tier` gains a third `Config.tier` value, `auto`, and a third preset, `sci-auto`: the cluster composition with the swarm mounted but shut. `./resolve` mounts `resolve_tier`, which appends `sci/tier-resolved` with `resolvedBy: 'model'` and the reason; the gates read the session's LAST such record (G0: `unresolved` until the first call, `tier` after a `balanced` resolution, then G1 as in cluster), so a balanced session is raised to cluster mid-way by a second call, and a cluster session is never lowered. The auto session appends no tier record on creation; the invariant reads the last record rather than any record, so a raised session may fan out. `SciTierResolvedData` gains optional `resolvedBy` and `reason`; the fixed compositions' payload is unchanged, so recorded snapshots stay valid. The default preset remains `sci-balanced`.

**The balanced text closes its third exit.** For a task one pass cannot cover — now naming "a real experiment or reproduction" beside research — the model has exactly two exits: a genuinely smaller real result whose scope is stated and whose numbers came from code that ran in the session, or `suggest_tier_upgrade`; a large-looking result no run produced is named and refused. The same sentence sits in the G2 refusal and the suggestion tool's description, and the auto text carries it with the raise as the second exit.

**Two reminders became pre-send checks.** The Citation and Memory reminders lose their escape clauses and are written as a walk the model performs before sending, with a stated outcome for the empty case ("passes the check with nothing to link/write"); the Memory check also refuses memory a real event of the session does not support. The File reminder keeps its clause because `sci-workspace` enforces the rule regardless.

**A delegated session is bounded by location.** `sci-workspace` refuses, under a new rule `delegation-scope`, any path a session with `delegationDepth ≥ 1` reaches that is inside the sandbox home but outside its own project (`header.cwd`) and outside the shared regions (`skills`, `spool-pending`, `private`). The rule runs before the path table for every filesystem tool, and `delegationScopeOperand` applies it to every path-looking operand of a shell command (`../p2/x`, `~/.claude/...`, `cd ..`). Paths outside the sandbox home (`/usr`, `/tmp`) are left to the sandbox's own permissions; the top-level session is unbounded.

**The consent property is asserted in `sci-guard`'s own suite.** A delegated child session carrying `approval/policy: never, source: delegation` meets the irreversible-action gate, is refused with no answerer consulted, and logs `sci/authorized` as `denied`, while the top-level session still reaches the answerer.

## Alternatives considered

- **Require the adversary only when the plan "claims load-bearing outputs."** No field carries that claim, and one the model fills is the producer's self-report the rule exists to bypass. The uniform rule costs one agent per fan-out; the producer/edge half keeps a read-only survey cheap.
- **Make `auto` a balanced session that forks itself on `suggest_tier_upgrade`.** The fork opens a new session and the user interface has to follow it; the raise inside one session keeps the workspace, the log, and the conversation. The fork stays for the fixed presets.
- **Make `sci-auto` the default preset.** The analysis recommends the task-driven tier over the user-bound one, but the swarm's spend is a product choice; the deployment flips `agent-presets.default`.
- **Bound delegated reads by tool group in `sci-agents`.** `permissions.ts` withholds whole tools, not paths; the child would keep the read tool or lose it. The path rule is the one that separates a sibling project from the child's own.
- **A provenance projection that ties delivered numbers to execution traces (§5 row 4).** Not built at the number: it needs a definition of "a number in a deliverable" that nothing holds today. Measured at the session instead — `sci-audit`'s summary gains `deliveriesWithoutExecution`, the count of deliveries made before any `execToolNames` call returned — and the mandatory adversary remains the line that refuses the fabricated result.

## Consequences

- A swarm of producers is refused at declaration; every fan-out carries an adversary and, when it produces, an edge into one. `sci-plan`'s tests describe the refusal and the accepted shape.
- `sci-auto` ships beside the two fixed presets; `resolve_tier` is in the tool catalog and the profile harness knows the `./resolve` subpath. `SciDenialRule` gains `unresolved`; `sci-audit` buckets it as any other rule.
- `sci-workspace` gains `RULE_DELEGATION_SCOPE`, `isOutsideDelegationScope`, `sandboxHomeSegments`, and `delegationScopeOperand`; the gate suite shows both tool families refusing a sibling project for a delegated session and admitting it for the top-level one.
- The example tree gains `auto.cordis.yml` and two keyless snapshots: the unresolved refusal, and the balanced refusal followed by the raise and the latch.
- The remaining three rows of the analysis are measured rather than gated. `sci-audit`'s `AuditFold` keeps a declaration open and re-emits its `sci_plan` row with `spawnedAgents`, `spawnedPersonasJson`, and `reconciled` (`fewer` / `match` / `more`) for every `subagent_<persona>` call and workflow agent start after it; the summary counts `planMismatches` (§5 row 8). `sci-agents` counts each child's web retrievals and the verbatim repeats among them onto the delegation row as `retrievalCalls` / `retrievalRepeats`, and `ui-sci-agents` shows them as a 检索 column in the delegation log (§5 row 9, a floor: a re-worded query is not a repeat). `sci-audit`'s summary counts `deliveriesWithoutExecution` (§5 row 4). Their limits are in the two packages' Known Limitations.
